자막 싱크 생성기
YouTube Studio에서 다운로드한 영어 자막 파일을 올리면 타임스탬프를 추출해 다른 언어 자막을 자동 생성합니다
사용 방법
1. YouTube Studio → 자막 → 영어 자막 편집 완료 후 다운로드 (.srt)
2. 아래에 영어 .srt 파일 업로드
3. 번역된 가사 붙여넣기 (언어별로 줄 수가 자막과 일치해야 함)
4. 생성된 각 언어 .srt 파일 다운로드 → YouTube Studio에 업로드
